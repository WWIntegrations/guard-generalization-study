# Visual design

The composition is based on the measured desktop and mobile layout of [FOLLOW.ART](https://follow.art/): condensed oversized type, an orange first screen, a curved moving ribbon and sage/pink sections with angled transitions. The reference received the [2026 Webby award for Best Visual Design - Function](https://winners.webbyawards.com/2026/websites-and-mobile-sites/features-design/best-visual-design-function/383443/followart). This project does not claim an Awwwards score or a visual award of its own.

The measured orange is `#F4793A`, with sage `#8E9487`, pink `#C5939D`, black and white. Anton and Departure Mono are distributed under their included OFL notices. They replace the reference's proprietary typefaces. No reference photographs, profiles, illustrations, source code or font files are included. The ribbon meshes, textures, source sheets, favicon and error page are original work for this study.

The original reference provides composition and motion direction. Different text, licensed font substitutes and original artwork produce measurable differences. Full pixel-for-pixel conformity has not been established.

The first screen is decorative. The inspector below reads a validated recorded bundle, shows actual public prompts and saved predictions, and exports the exact validated file bytes. Browser animation does not execute inference or show a live model response. The absolute animation phase is available to the local capture harness; Pause, reduced motion and a static artwork fallback preserve access to the study.

The architecture SVG was exported locally through Darwin from an original five-node specification. It shows exposure audit, protocol freeze, isolated inference, false-positive accounting and offline verification. It is a static explanation of the mechanism, not an execution trace. Its XML and browser rendering were checked separately from the study's numerical results.

The custom 404 page preserves the palette and type, includes English and Polish copy, and links back to the study. There is no hosted deployment in this repository's initial publication scope.

Final browser measurements and recording provenance belong in `verification.md` and `media-provenance.json` after the actual recorded study has been inspected. A successful code test alone is not a visual measurement.
